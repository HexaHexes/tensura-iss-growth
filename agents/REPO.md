**Repo:** `HexaHexes/tensura-iss-growth` · **Mod ID:** `tensura_iss_growth` · **Branch:** `main`
**Platform:** Minecraft 1.21.1 / NeoForge 21.1.259 / JDK 21 · **Jar:** `build/libs/tensura_iss_growth-<version>.jar`

Re-weaves Iron's Spells 'n Spellbooks gear into Tensura's EP ladder and Gear
Evolution chains, replacing the official `tensura_iron_spells` integration's
flat terminal bands with progression (armor sets, spell books, weapons), plus
optional coverage for four ISAS addons. The rebalanced datapack ships inside the
jar, generated by this mod's own datagen.

**Dependencies**
- Required (planned, not yet wired in `build.gradle`): Minecraft, NeoForge, `tensura`, `manascore`, `irons_spellbooks`, `tensura_iron_spells`.
- Optional: `gearevolution` (chains are inert without it), and the four addon mods — `allthewizardgear`, `wind_spellbooks`, `leylines`, `resonant_arcana`.

**Test:** `./gradlew runGameTestServer` — `TensuraIssGameTests` (1 smoke test). `expectedTests = 1` in `build.gradle` must match the `@GameTest` count.

**Gotchas**
- **Path ownership vs `tensura-iaf-growth`.** Both mods ship overrides in shared
  namespaces. This mod owns `data/irons_spellbooks/**`, the four addon
  namespaces, and `data/gearevolution/addon_chains/irons_spellbooks/**`. It must
  NOT ship files at paths `tensura-iaf-growth` owns (notably the adamantite
  armor override at `data/tensura/gear_existence/` and the silver rungs at both
  its paths) — where an overlap is genuinely sanctioned, ship byte-identical
  copies so the pack-priority race has no loser. Keep the datagen path-set
  assertions honest when adding files.
- **gear_existence `type` is a plain `ResourceLocation`.** Files referencing an
  absent optional mod's items parse fine and are inert at runtime (lookup by
  item id misses) — this is what makes single-pack optional addons safe. Do not
  "fix" this with conditional packs, and do not assume it holds for every field
  (verify any new field that resolves holders at parse time).
- **Chain targets into absent optional items** (e.g. AllTheWizardGear spell
  books as top rungs) depend on Gear Evolution resolving missing targets
  lazily — verify against GE bytecode before relying on it (tracked in the
  design issue).
- The official `tensura_iron_spells` jar owns the same
  `data/irons_spellbooks/gear_existence/` paths; ours wins by pack priority
  only if placed later — same mechanism `tensura-iaf-growth` uses against
  `tensura_iaf`. Any re-band of its files must be recorded in the README's
  tables so drift is visible.
- Version single source of truth: the `mod_version` line in `gradle.properties`
  (ci.yml reads it, version-bump.yml rewrites it).
